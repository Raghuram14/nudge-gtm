Engineering diagnosis starts with **context**, not a bigger chart.

If cycle time is up, the next questions are associated causes: review queues, blocked work items, concentrated reviewer load, downstream services. Those answers live in relationships — work item implemented_by pull request, pull request triggers build — not in a single tool tab.

Antarang’s Knowledge Graph is the model for that context. Mock investigations on the marketing site are labeled **Example**. Correlation is not written as causation.
